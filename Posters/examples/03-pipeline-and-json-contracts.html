What is Pezen Waiter?

Ordering at a self-service table iPad should feel effortless, yet navigating nested menus and modifiers often slows guests down. Pezen Waiter is a conversational voice ordering module integrated into the Pezen Table App that lets guests speak naturally, revise quantities mid-sentence, and confirm complex orders without waiting for staff.

What it does

Pezen Waiter combines on-device voice detection with a multi-stage language pipeline to turn casual spoken requests into verified POS actions:

  • Voice Activity Detection (VAD) which allows the customer and the virtual waiter to “take turns” automatically.

  • Speech-to-text (STT) which converts audio into text needed for processing the customer’s order.

  • Disfluency repair to handle the natural imperfections of spoken language, such as hesitations, filler words, and self-corrections.

  • Intent extraction is where the language-processing happens and determines what the customer wants.

  • Deterministic validation for validating menu items or operations that didn’t make sense and replacing them with a proper reply.

Intent Extraction & Validation

Every voice interaction follows a structured pipeline. The iPad captures the customer's speech and detects when they have finished speaking. The REQUEST is then processed by the AI pipeline, which converts speech into text, extracts the customer's intent, validates the generated actions against the restaurant's menu, and returns a structured RESPONSE for the app to execute.

REQUEST Type

{ "session_id": String "restaurant_id": String "input": { "transcript": String? "audio_segments": [String]? } "cart": [{ "menu_id": String "name": String "quantity": Int "price": Int "note": String? }] "catalog": [{ "menu_id": String "name": String "category": String? "description": String? "available": Bool "price": Int }] "history": [{ "role": String "text": String }] }

RESPONSE Type

{ "session_id": String "reply": String "actions": [{ "type": String "menu_id": String? "quantity": Int? "note": String? }] "suggestions": [String] "transcript": String? }

List of action types:

  • add_item — Adds a menu item to cart

  • update_quantity — Adjusts item count

  • remove_item — Removes item from cart

  • update_note — Sets preparation notes

  • clear_cart & confirm_order
